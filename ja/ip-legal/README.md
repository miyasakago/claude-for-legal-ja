# IP Counsel プラグイン

知的財産プラクティス: 商標、著作権、特許、営業秘密、オープンソース。警告状(Cease & Desist)および DMCA テイクダウン通知の送信・受領のドラフトとトリアージ、商標クリアランス初回パスとフリーダム・トゥ・オペレート(FTO)トリアージの実行、契約書中の IP 条項のレビュー、登録および更新期限の追跡、オープンソースライセンス遵守チェックを行います。コールドスタート・インタビューが書き込むプラクティスプロファイルを軸に構築されており、プラグインは*あなたの*エンフォースメント・スタンス、ポートフォリオ、承認マトリックスを学びます — 汎用のものではありません。

**すべての出力は弁護士レビューのためのドラフトであり、引用付き、フラグ付き、ゲート付きで、法的結論ではありません。** プラグインが作業を行います: 文書を読み、あなたのプレイブックを適用し、論点を見つけ、メモをドラフトします。弁護士がレビューし、検証し、決定します。引用はソース別にタグされ、どれが調査ツールから来て、どれが要チェックかが分かります。秘匿特権マーカーは保守的に適用され、誤って放棄されることはありません。重大な行為 — 提訴、送付、執行 — は明示的な確認の背後にゲートされます。

## 想定ユーザー

| Role | 主なワークフロー |
|---|---|
| **インハウス IP カウンセル** | エンフォースメント判断、条項レビュー、ポートフォリオ監督、FTO トリアージ |
| **IP パラリーガル / スペシャリスト** | ポートフォリオと更新の追跡、クリアランス初回パス、案件インテーク |
| **ブランド保護マネージャー** | C&D、DMCA テイクダウン、ウォッチサービスのフォローアップ |
| **IP 出願人(商標 / 著作権)** | クリアランス、条項レビュー、ポートフォリオ維持 — *特許クレーム作成は対象外* |
| **法律事務所 IP アソシエイト** | クライアント別の案件ワークスペース、クリアランスと FTO トリアージ、条項レビュー |
| **IP ポートフォリオ管理のリーガル・オプス** | 登録トラッカー、更新期限、OSS コンプライアンス・チェック |

このプラグインは特許クレームを**作成しません**。クレーム戦略を伴う特許出願はスペシャリスト技能で、特許代理人または特許弁護士が必要であり、汎用ツールに外注すべきではありません。ここでの特許作業は、FTO トリアージ(この製品は他者の特許でブロックされているか?)、契約書中の IP 条項レビュー、ポートフォリオ更新追跡、侵害トリアージに限定されます。

## 初回実行: コールドスタート・インタビュー

初回利用時、プラグインはあなたにインタビューします — 10〜15 分、会話形式 — あなたのプラクティスが実際にどう動くかを学ぶために。プラクティスエリアの構成、法域フットプリント、エンフォースメント・スタンス、承認マトリックス、エスカレーション・トリガーを尋ねます。次にポートフォリオリスト、ブランドガイドライン、C&D テンプレート、エンフォースメント・プレイブック、OSS ポリシーなど、あれば共有してくださいと依頼します — 再入力ではなく抽出するためです。

学んだことを `~/.claude/plugins/config/claude-for-legal-ja/ip-legal-ja/CLAUDE.md` — あなたのプラクティスについての平易な英語の文書 — に書き込み、本プラグインのすべてのスキルが、何かを行う前にこれを読みます。あなたは設定ファイルではなく、この文書を編集します。

```
/ip-legal-ja:cold-start-interview
```

**プラクティスエリア構成.** セットアップの早い段階で、実際に扱う IP 領域 — 商標、特許、著作権、営業秘密、オープンソース、またはすべて — を尋ねます。プラグインは実務しない領域の質問をスキップします。設定は複数の領域を並行で保持でき、貼り付け内容から明白でないとき各スキルがどの領域かを尋ねます。

**エンフォースメント・スタンス.** 主張レター送付について aggressive / measured / conservative スペクトルのどこに位置するか、各レタータイプを誰が承認するかを尋ねます。スタンスは cease-and-desist、takedown、infringement-triage スキルのデフォルトを切り替えます。

## コマンド

| コマンド | 機能 |
|---|---|
| `/ip-legal-ja:cold-start-interview` | コールドスタート・インタビューを実行(または再実行) |
| `/ip-legal-ja:cease-desist [context]` | 警告状 — 送信、または受領したものをトリアージ、CLAUDE.md が要求する承認ルーティング付き |
| `/ip-legal-ja:takedown [context]` | DMCA テイクダウン — 送信、受領通知への対応、またはカウンター通知の作成 |
| `/ip-legal-ja:clearance [mark]` | 商標クリアランス初回パス — knockout + 混同分析、弁護士の最終サインオフ |
| `/ip-legal-ja:fto-triage [product / claim scope]` | フリーダム・トゥ・オペレート・トリアージ — 弁護士レビュー用にブロック・リファレンスを表面化 |
| `/ip-legal-ja:invention-intake [disclosure]` | 発明開示書初回パス・スクリーニング — 新規性、進歩性、§101、出願期限、検知可能性、戦略的価値 |
| `/ip-legal-ja:infringement-triage [context]` | 侵害トリアージ — 追求する価値があるか、どう追求するか |
| `/ip-legal-ja:ip-clause-review [file]` | 契約書中の IP 条項レビュー — 譲渡、ライセンス許諾、IP 補償、OSS 表明 |
| `/ip-legal-ja:oss-review [repo / file list]` | オープンソースライセンス・コンプライアンス・チェック — コピーレフト義務、表示、ライセンス互換性 |
| `/ip-legal-ja:portfolio` | 登録および更新トラッカー — 何が期限内か、何が提出済みか、何にアクションが必要か |
| `/ip-legal-ja:matter-workspace` | 案件ワークスペースを管理(マルチクライアント・プライベートプラクティスのみ) — new、list、switch、close、none |

## スキル

| スキル | 目的 |
|---|---|
| **cold-start-interview** | 初回実行時のインタビューで `~/.claude/plugins/config/claude-for-legal-ja/ip-legal-ja/CLAUDE.md` を書き込む |
| **cease-desist** | C&D の作成またはトリアージ。送信前に承認マトリックスを通す |
| **takedown** | DMCA 通知、受領テイクダウンへの対応、またはカウンター通知 |
| **clearance** | 提案マークの knockout 調査 + 混同のおそれの初回パス |
| **fto-triage** | FTO トリアージ — ローンチ前に弁護士が読むべき先行文献にフラグ |
| **invention-intake** | 発明開示書の初回パス特許性スクリーニング — 新規性、進歩性、§101、出願期限、検知可能性、戦略的価値 |
| **infringement-triage** | 明らかな侵害を踏まえ判断: 無視 / ソフトレター / C&D / 提訴 |
| **ip-clause-review** | MSA、SOW、ライセンス、業務委託契約中の IP 条項をレビュー |
| **oss-review** | リポジトリ中のオープンソースライセンスを OSS ポリシーに照らしてチェック |
| **portfolio** | 登録台帳、更新期限、ステータスダッシュボード |
| **matter-workspace** | マルチクライアント・プラクティス用の案件ワークスペースを作成、リスト、切替、クローズ。各クライアント/案件を分離し、コンテキストが横断しないように |

## インタラクティブコマンド vs スケジュールエージェント

上記のコマンドは呼び出したときに実行されます — 案件作業中向け。下記のエージェントはスケジュールで実行されます — あなたが見ていない間に動くもの向け:

| エージェント | 監視対象 | デフォルトの実行頻度 |
|---|---|---|
| **ip-renewal-watcher** | ポートフォリオ台帳 — 今後 90 日に期限を迎えるもの(更新、宣誓書、維持年金)を計算し、ランク付き期限レポートを投稿 | 週次 |

## コネクターと引用検証

**まず調査ツールを接続してください — 引用ガードレールはこれに依存します.** 接続がなければ、すべての引用は `[verify]` タグ付きで、各成果物の上にあるレビューアーノートはソースが未検証であることを記録します。プラグインはどちらでも動作します。調査ツールが接続されているとき、検証作業をより多く代行します。

本プラグインの法律調査コネクターは単なるデータソースではありません — 検証済み引用と要チェック引用の違いを生むものです。**CourtListener**(米国判例、PACER ドケット、引用検証)または **Descrybe**(一次法検索、引用取扱状況、引用文言検証)経由で取得された引用はソースタグ付きで、辿れます。モデル知識や Web 検索からの引用は `[verify]` または `[verify-pinpoint]` 付きで、依拠する前に一次資料でチェックすべきです。プラグインは引用を階層化し、検証時間が重要な箇所に注がれるようにします。

## インテグレーション

`.mcp.json` で設定されているコネクター:

- **Solve Intelligence** — 特許および非特許文献検索、SEP 技術規格、先行技術、クレーム分析
- **CourtListener** — 米国判例、PACER ドケット、引用検証
- **Descrybe** — 概念や文言による一次法調査、引用取扱状況、引用文言検証
- **Slack** — メッセージ検索、チャンネル閲覧、ディスカッション検索
- **Google Drive** — 文書の検索、閲覧、取得

特許リサーチが接続されていると: FTO と先行技術スキルはユーザー提供リストに頼らず文献を自動取得します。

判例ツールが接続されていると: クリアランスと侵害トリアージのスキルが先例を検証し、引用した判例が今も good law かをチェックします。

Drive または Slack が接続されていると: ポートフォリオ・エクスポート、C&D テンプレート、エンフォースメント・ログの更新が、指示したチャンネル経由でルーティングされます。

## クイックスタート

### 1. インタビューを受ける

```
/ip-legal-ja:cold-start-interview
```

10〜15 分。ポートフォリオリスト、ブランドガイドライン(あれば)、C&D テンプレート(あれば)、OSS ポリシー(あれば)を共有できるように準備しておいてください。

設定は `~/.claude/plugins/config/claude-for-legal-ja/ip-legal-ja/CLAUDE.md` に保存され、プラグイン更新後も残ります。

### 2. マークをクリアする

```
/ip-legal-ja:clearance "APEXLEAF"
```

出力: knockout ヒットリスト、混同のおそれの要因分析、弁護士レビュー用フラグ。go / no-go ではありません。

### 3. 期限を確認する

```
/ip-legal-ja:portfolio
```

出力: 今後 90 日に更新、宣誓書、または維持年金の期限を持つ登録を、緊急度別にグループ化。

## 設定

プラグインはユーザー固有設定を以下から読み込みます:

```
~/.claude/plugins/config/claude-for-legal-ja/ip-legal-ja/CLAUDE.md
```

このパスはプラグイン更新後も維持されます。プラグインに同梱される `CLAUDE.md` はテンプレートで、アップグレードのたびに置き換えられます。コールドスタート・インタビューが上記の設定パスに記入済みバージョンを書き込み、以後何かが変わったらそのファイルを直接編集します。

## 学習の仕方

`~/.claude/plugins/config/claude-for-legal-ja/ip-legal-ja/CLAUDE.md` のプラクティスプロファイルは静的ではありません — プラグインを使うほど改善されます。スキルが、出力に使ったデフォルトのうちチューニングすべきものを伝えます。`ip-renewal-watcher` エージェントがポートフォリオ台帳を追跡し、あなたの実行頻度に応じて近づく更新期限を表面化します。セットアップを再実行することも、ファイルを直接編集することも、スキルに新しい立場を記録するよう伝えることもできます。

## 注記

- すべてのスキルはまずプラクティスプロファイルを読みます。プレースホルダーを見つけたら停止し、`/ip-legal-ja:cold-start-interview` の実行を伝えます。汎用フォールバックはありません — 汎用 IP スタンスはスタンスなしより悪いものです。
- C&D の送付は戦いを始めます。`/ip-legal-ja:cease-desist` スキル自体は何も送りません。作成し、承認マトリックスのエントリーを表面化し、承認者を待ちます。
- `/ip-legal-ja:clearance` と `/ip-legal-ja:fto-triage` は**初回パス**トリアージです。出力は弁護士向けの調査パッケージで、クリアランス意見ではありません。スキルは実行のたびにそう伝えます。
- `/ip-legal-ja:oss-review` はライセンス義務と非互換性をフラグします。商用利用判断を承認するものではありません — エンジニアリングと法務が一緒に決めます。
- 特許クレーム作成は意図的にスコープ外です。本プラグインは特許出願スペシャリストと並走しますが、置き換えるものではありません。
