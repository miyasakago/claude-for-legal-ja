# ダッシュボード・テンプレート

*ダッシュボード提供ガードレールから参照されます。ダッシュボードはシンプルで一貫性のある形に保ってください — 価値は理解の速度であり、ビジュアルの洗練ではありません。*

## 構造(上から下へ)

1. **タイトルとメタデータ。** これが何か、いつ生成されたか、何をカバーしているか。1 行で。
2. **サマリー統計。** 重要なカウントをカラーコード付きで。「40 findings: 🔴 3 blocking · 🟠 8 high · 🟡 15 medium · 🟢 14 low — 6 due this week」。これが最も価値のある行。スキャナブルに保つ。
3. **レビューアー注記。** 他の出力と同じ 1 ブロック形式。Sources、scope、flags、before-relying。ダッシュボードでも安全メタデータをスキップしない。
4. **チャート。** 最大 1〜2 個。形状を示すものを選ぶ:
   - **リスク分布**(棒グラフ): 重大度別カウント。所見、論点、フラグに使用。
   - **カテゴリ別内訳**(円グラフまたは積み上げ棒): タイプ別カウント。OSS ライセンス、契約タイプ、案件カテゴリに使用。
   - **タイムライン**(簡易ガントまたはソート済みテーブル): 日付順。更新台帳、期限トラッカー、クロージング・チェックリストに使用。
   - 2 つを超えない。5 つのチャートがあるダッシュボードはレポートであり、レポートはテーブルより読みにくい。
5. **テーブル。** ソート可能、フィルタ可能、重大度/ステータスでカラーコード化。列: 元の出力にあったもの、画面に収まるよう削減。「詳細」または「ノート」列は最後に置く — 切り詰められやすい列。
6. **デシジョンツリー。** テキスト出力と同じ選択肢。「次は何?」

## 表示面ごとのレンダリング

- **Cowork / Claude Desktop:** HTML アーティファクト。自己完結、単一ファイル、インライン CSS。外部依存なし、CDN なし、npm なし。テーブル: `data-sort` 属性付き HTML `<table>` と小さなインライン JS ソーター。チャート: 棒グラフにはインライン SVG または Unicode ブロック文字。JS は最小限に保つ — ソートとフィルタリングのみ、それ以外なし。
- **Claude Code:** 同じ HTML ファイルをプラグインの outputs フォルダ(`~/.claude/plugins/config/claude-for-legal-ja/<plugin>/outputs/dashboard-<topic>-<date>.html`)に書き出し、ユーザーに開くよう伝える: macOS なら `open <path>`、または「ブラウザで開いてください」。サマリー統計用に Unicode ブロックチャートを使った markdown 版も生成し、ユーザーがターミナルを離れずに形状を確認できるようにする。
- **Excel(任意、適合する場合):** `tabular-review`、`renewal-tracker`、`entity-compliance`、およびユーザーが会議に持ち込むか非技術的なステークホルダーと共有するもの向け。既存の Excel 出力仕様を使用。formula-injection 防御を適用する。
- **信頼できない入力をエスケープする(すべてのダッシュボード、毎回適用)。** 本セッション外から来た値 — サードパーティのマニフェストから取得した OSS パッケージ/ライセンスフィールド、相手方の契約書テキスト、デューデリジェンス所見、ベンダー名、案件記述、ユーザーまたは VDR が供給した任意の文字列 — はドキュメントに入る前に HTML エスケープしなければならない。テーブルセル、サマリー行、チャートラベル、ツールチップテキストに書き込むときに、`&`、`<`、`>`、`"`、`'` をエンティティにエスケープする。インライン JS ソーター/フィルタでは、セルテキストを `textContent` で設定し、`innerHTML` を決して使わない。信頼できない文字列を補間する `<script>` ブロックを出力しない。スキームチェック(`http:` / `https:` / `mailto:` のみ)なしで信頼できない URL を `href` または `src` にレンダリングしない。これは Excel 側の formula-injection 防御の HTML 表面版 — 同じ脅威(攻撃者制御のセル内容)、異なる実行表面(スプレッドシート数式ではなくブラウザ JS)。レビューアーがブラウザで開くダッシュボードは信頼境界。そう扱う。

## 退屈に保つ

- **カラーパレット:** 重大度には赤 / オレンジ / 黄 / 緑。中立にはグレー。ステータスには青。それ以外なし。
- **アニメーションなし、フレームワークなし、外部フォントなし。** オフラインで壊れるダッシュボードは、壊れるダッシュボード。
- **凝ったレイアウトなし。** サマリー、レビューアー注記、チャート、テーブル、デシジョンツリー。上から下へ。すべてのダッシュボードが同じ見た目で、読み手がどこを見ればよいか分かるように。
- **markdown 版は重要。** ターミナルにいてブラウザを開かないユーザーもいる。Unicode バー付きのサマリー統計行(例: `🔴 ███ 3  🟠 ████████ 8  🟡 ███████████████ 15  🟢 ██████████████ 14`)で形状を伝える。
