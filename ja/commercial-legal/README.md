# 商取引法務プラグイン

社内の商取引契約のワークフロー:ベンダー契約レビュー、NDA トリアージ、SaaS サブスクリプションのレビュー、更新追跡、エスカレーション振り分け、ビジネスステークホルダー向けサマリー。チームのプラクティスプロファイル(コールドスタート・インタビューによって書き込まれる)を中心に構築されており、汎用のものではなく*あなたの*プレイブックをプラグインが学習します。

**すべての出力は、弁護士レビューのための下書きです — 引用と注釈、ゲートが付された、結論ではないドラフトです。** プラグインは作業を行います:文書を読み、プレイブックを適用し、論点を見つけ、メモを起草します。弁護士がレビューし、検証し、判断します。引用はソース別にタグ付けされ、どれがリサーチツール由来でどれを確認する必要があるかが分かるようになっています。秘匿特権マーカーは保守的に適用され、不注意で放棄されないようになっています。提出・送信・締結といった重要な行動は、明示的な確認の後ろにゲートされます。

## 想定ユーザー

| 役割 | 主なワークフロー |
|---|---|
| **商取引法務カウンセル** | ベンダー契約レビュー、エスカレーションの振り分け、ステークホルダー向けサマリー |
| **契約マネージャー/パラリーガル** | NDA トリアージ、更新追跡、ファーストパスレビュー |
| **調達** | 更新の認知、受け手としてのステークホルダー向けサマリー |
| **セールス/BD** | 法務に投げる前の NDA セルフサービス・トリアージ |

## 初回実行:コールドスタート・インタビュー

初回使用時、プラグインはあなたにインタビューします — 10 分程度、会話形式で — あなたのチームが実際にどう働いているのかを学習するためです。プレイブックの立場、エスカレーションのルール、あなたのデスクに届いてうんざりするのはどんな案件か、を尋ねます。続いて、直近で締結された 5〜10 件の契約書(多いほどよく、20 件あれば明確なパターンが見えます)を共有するよう依頼し、立場が実際にどう着地しているかを把握します。

学習したことは `~/.claude/plugins/config/claude-for-legal-ja/commercial-legal-ja/CLAUDE.md` に書き込まれます — このプラグイン内のすべてのスキルが、作業を始める前に読み取る、あなたのチームに関する平易な英語(日本語版では日本語)の文書です。設定ファイルではなくこの文書を編集します。

```
/commercial-legal-ja:cold-start-interview
```

**プレイブックのサイド。** セットアップ初期に、**セールスサイド**のプレイブック(自社が製品/サービスを売る側。自社がベンダー。通常は自社の契約書式)、**パーチェシングサイド**のプレイブック(ベンダーから買う側。自社がカスタマー。通常は相手方の書式)、または両方のどちらを構築するかを尋ねられます。回答によってほぼすべてのプレイブック立場が反転します — 責任上限、補償の方向、解除権、IP の帰属 — なので最初に決めるべき事項です。両方を選んだ場合、セットアップはまずセールスサイドを構築します。後で `/commercial-legal-ja:cold-start-interview --side purchasing` を実行してもう一方を構築します。設定は両方を並列で保持し、レビュースキルはプレイブックを読む前にどちらのサイドが適用されるかをチェックします。

## コマンド

| コマンド | 機能 |
|---|---|
| `/commercial-legal-ja:cold-start-interview` | コールドスタート・インタビューの実行(または再実行) |
| `/commercial-legal-ja:review [file]` | ベンダー契約、NDA、SaaS サブスクリプションをプレイブックに照らしてレビュー |
| `/commercial-legal-ja:renewal-tracker` | 今後 90 日以内に更新を迎える契約と、解約期限の一覧 |
| `/commercial-legal-ja:escalation-flagger` | 論点を適切な承認者に振り分け、依頼文を起草 |
| `/commercial-legal-ja:amendment-history [file(s)]` | ベース契約とすべての変更契約にわたる変更履歴をたどる |
| `/commercial-legal-ja:review-proposals` | モニターエージェントが起こした保留中のプレイブック更新提案を順にレビュー |
| `/commercial-legal-ja:matter-workspace` | 案件ワークスペースの管理(マルチクライアントの私的実務のみ) — new、list、switch、close、none |

## スキル

| スキル | 目的 |
|---|---|
| **cold-start-interview** | `~/.claude/plugins/config/claude-for-legal-ja/commercial-legal-ja/CLAUDE.md` を書き込む初回インタビュー |
| **vendor-agreement-review** | プレイブック対契約の完全な乖離分析とレッドライン |
| **nda-review** | 高速な GREEN/YELLOW/RED トリアージで、法務が読む必要がある NDA に絞り込み |
| **saas-msa-review** | サブスクリプション固有のオーバーレイ:自動更新、価格上昇、データエクスポート、SLA |
| **renewal-tracker** | 解約期限の台帳。迫っているものを浮かび上がらせる |
| **escalation-flagger** | 論点をエスカレーションマトリクスに照合し、承認者への依頼文を起草 |
| **stakeholder-summary** | 法務レビューを 2 段落のビジネス翻訳に |
| **amendment-history** | ベース契約と変更契約全体の変更点を要約、または特定の条項を現行の支配文言までたどる |
| **matter-workspace** | マルチクライアント実務向けの案件ワークスペースの作成、一覧、切替、終了。各クライアント/案件を分離し、コンテキストが互いに漏れないようにする |

## インタラクティブコマンドとスケジュール実行エージェントの違い

上記のコマンドは、あなたが起動したときに走ります — 案件に取り組んでいるときのためのものです。下記のエージェントはスケジュールで走ります — あなたが見ていないときに進んでいるもののためのものです:

| エージェント | 監視対象 | デフォルト頻度 |
|---|---|---|
| **renewal-watcher** | 更新台帳 — 今後 90 日以内に来るものを投稿し、0〜13 日以内の解約期限は赤フラグでエスカレーション | 週次(月曜) |
| **deal-debrief** | 直近で締結された契約のプレイブック乖離を確認。記憶が新しいうちに文脈を記録するよう弁護士に促す | 週次(月曜) |
| **playbook-monitor** | 乖離ログ — ある条項が直近 12 か月のローリングウィンドウで 5 回以上オーバーライドされた場合にプレイブック更新を提案 | データトリガー(各 deal-debrief 実行後) |

## インテグレーション

**まずリサーチツールを接続してください — 引用ガードレールはそれに依存します。** 接続されていないと、すべての引用は `[verify]` タグ付きとなり、各成果物の上の Reviewer note(レビューアー注記)にソース未検証であることが記録されます。スキルはどちらの場合でも動作します。リサーチツール(CourtListener)は検証作業をあなたから取り除くだけです。


`.mcp.json` に設定されたコネクターを同梱しています:

- **Ironclad** — 契約ライフサイクル管理
- **DocuSign** — 署名ステータスとエンベロープ追跡
- **Slack** — メッセージ検索、チャンネル読み取り、議論の発見(汎用バケット)
- **Google Drive** — 文書の検索、読み取り、取得(汎用バケット)

[CLM] を接続すると:同じ相手方との過去契約のチェック、更新台帳の一括ロード、レビューメモを添付したレコードの作成が可能になります。

DocuSign を接続すると:署名ステータスの追跡、承認者の順序でエンベロープを振り分けます。

## クイックスタート

### 1. インタビューを受ける

```
/commercial-legal-ja:cold-start-interview
```

10 分間。直近で締結された 5〜10 件の契約を共有できるよう準備してください(多いほどよく、20 件あれば明確なパターンが見えます)。

設定は `~/.claude/plugins/config/claude-for-legal-ja/commercial-legal-ja/CLAUDE.md` に保存され、プラグイン更新後も維持されます。

### 2. 契約をレビュー

```
/commercial-legal-ja:review vendor-msa.pdf
```

出力:プレイブックに照らした乖離ごとのメモ、具体的なレッドライン文言、指名された承認者付き。

### 3. 更新予定の確認

```
/commercial-legal-ja:renewal-tracker
```

出力:今後 90 日以内に解約期限を迎えるすべての契約、緊急度別にグループ化。

## 学習する仕組み

`~/.claude/plugins/config/claude-for-legal-ja/commercial-legal-ja/CLAUDE.md` のプラクティスプロファイルは静的ではありません — プラグインを使うほどに改善されます。スキルは、チューニングすべきデフォルトが出力に使われたときにそれを知らせます。`playbook-monitor` エージェントは、実務がプレイブックから乖離したときに更新を提案します。セットアップを再実行する、ファイルを直接編集する、または新しい立場を記録するようスキルに指示することができます。

## 注意

- プラグインは、ほとんどのレビューにおいて自社が**カスタマー**であると想定します。自社がベンダーである場合はフラグを立て、レビューはプレイブックの極性を反転させます。
- NDA トリアージは非弁護士のセルフサービスを前提に作られています。GREEN は「署名へ回せる」を意味します。交渉はしません。
- 更新追跡は、このプラグインを通じてレビューされた契約、または [CLM] から一括ロードされた契約のみを把握します。インストール前に署名された契約は一度限りのスキャンが必要です。
