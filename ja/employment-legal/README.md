# 雇用法務カウンセル・プラグイン (Employment Counsel Plugin)

インハウス雇用法務ワークフロー: 採用レビュー、解雇レビュー、ポリシードラフト、ハンドブック更新、法域認識を備えた賃金・労働時間 Q&A。コールドスタートで学習する法域フットプリントを中心に構築 — プラグインはあなたがどの州に従業員を持ち、各州で何が異なるかを把握しています。

**すべての出力は弁護士レビュー用のドラフトであり — 引用付き、フラグ付き、ゲート付き — 法的結論ではありません。** プラグインが作業します: 文書を読み、あなたのプレイブックを適用し、論点を見つけ、メモを起草します。弁護士がレビュー・検証・決定します。引用は出典別にタグ付けされ、どれが研究ツールから来て、どれが確認を要するかが分かります。秘匿特権マーカーは保守的に適用され、誤って放棄されないようにします。結果を伴う行動 — 提出、送付、実行 — は明示的な確認の背後にゲートされます。

## 対象ユーザー

| 役割 | 主なワークフロー |
|---|---|
| **雇用法務カウンセル** | 解雇レビュー、ポリシードラフト、賃金・労働時間分析 |
| **HR ビジネスパートナー** | 採用レビュー、ハンドブック質問、賃金・労働時間の一次 Q&A |
| **GC** | 高リスク解雇および RIF のエスカレーション先 |

## 初回実行: コールドスタート

従業員がいる州・国を尋ね、ハンドブックと直近の解雇メモ 3 通を読み、法域認識付きのエスカレーション表を構築します。

```
/employment-legal-ja:cold-start-interview
```

設定は `~/.claude/plugins/config/claude-for-legal-ja/employment-legal-ja/CLAUDE.md` に保存され、プラグイン更新を超えて維持されます。

## 前提条件

- **永続データのパス。** 休職台帳、調査ログ、海外展開トラッカーは `~/.claude/plugins/config/claude-for-legal-ja/employment-legal-ja/` に書き込まれます。これはプラグイン更新を超えて生き残るバージョン非依存のパスです。これらのファイルには秘匿特権の対象となる個人人事情報が含まれます — そのディレクトリのバックアップとアクセス制御を確認してください。
- **法務リサーチへのアクセス。** このプラグインのスキルは、実質的な法的ルール(給与閾値、競業避止義務の執行可能性、最終給与の支払時期、権利放棄合意の検討期間、国別雇用法フレームワーク等)を意図的に保存しません。法域固有のルールはすべてレビュー時にリサーチ・引用されます。セッションが依拠する研究ツール(ウェブ検索、社内法務リサーチ連携、チームの参考資料)にアクセスできるようにしてください。
- **外部弁護士。** 難しい判断や新法域については、外部弁護士の関与なしには国別または法域固有の法的助言は出力されません。

## スキル

| スキル | 機能 |
|---|---|
| `/employment-legal-ja:cold-start-interview` | コールドスタート・インタビュー — ハンドブック + 解雇メモから法域フットプリント + エスカレーションルールを学習 |
| `/employment-legal-ja:hiring-review` | オファーレター + 競業避止義務レビュー、法域チェック |
| `/employment-legal-ja:termination-review` | 高リスクフラグ検知付きの解雇レビュー |
| `/employment-legal-ja:policy-drafting [topic]` | 必要に応じて州別補足付きのポリシードラフト |
| `/employment-legal-ja:wage-hour-qa [question]` | 法域認識を備えた賃金・労働時間または一般雇用 Q&A |
| `/employment-legal-ja:worker-classification` | 提案された労働者の関与を分類し、誤分類ギャップをフラグ |
| `/employment-legal-ja:expansion-kickoff [country]` | 新規国への国際展開計画のキックオフ |
| `/employment-legal-ja:expansion-update [country]` | 進行中の展開トラッカーを更新 |
| `/employment-legal-ja:investigation-open` | 新規内部調査案件を開設 |
| `/employment-legal-ja:investigation-add` | 開設中の調査に文書、インタビューノート、観察を追加 |
| `/employment-legal-ja:investigation-query` | 開設中の調査ログに対して質問 |
| `/employment-legal-ja:investigation-memo` | 秘匿特権下の調査メモをドラフトまたは更新 |
| `/employment-legal-ja:investigation-summary` | 調査メモから対象者別サマリーをドラフト |
| `/employment-legal-ja:leave-tracker` | 開設中の休職について期日アラートと必要判断をチェック |
| `/employment-legal-ja:log-leave` | 休職台帳に新規エントリーを追加 |
| `/employment-legal-ja:matter-workspace` | 案件ワークスペース管理(複数クライアントのプライベートプラクティス専用) — new, list, switch, close, none |
| **handbook-updates** | 提案変更を現行ハンドブックと差分比較し、州別補足への影響をフラグ |

参照スキル `internal-investigation` と `international-expansion` は詳細なフレームワークとテンプレートを担います — モード別スキルが必要に応じてロードします。

## インタラクティブスキル vs スケジュール実行エージェント

上記のスキルはあなたが呼び出したときに実行されます — 案件に取り組んでいるときのため。下記のエージェントはスケジュールで実行されます — あなたが見ていない間に動くもののため:

| エージェント | 監視対象 | デフォルトの実行周期 |
|---|---|---|
| **leave-tracker** | 法定期限のある開設中の休職 — FMLA(米国家族・医療休暇法)、州レベルの相当法(CA CFRA(カリフォルニア州家族権法)、NY PFL(ニューヨーク州有給家族休暇))、USERRA(米国軍人雇用権利法)、合理的配慮としての ADA(米国障害者法)休暇; 期日を逃す前に判断ポイントアラートを発火 | 週次(月曜) |

## 学習の仕組み

`~/.claude/plugins/config/claude-for-legal-ja/employment-legal-ja/CLAUDE.md` のプラクティスプロファイルは静的ではありません — プラグインを使うほどに改善されます。出力で調整すべきデフォルトが使用されたとき、スキルが知らせます。セットアップを再実行、ファイルを直接編集、または新しい立場を記録するようスキルに伝えることができます。

## 注意点

- 法域認識こそが要点です。プラグインはカリフォルニアの最終給与が解雇当日支払い、ニューヨークは次回通常給与日支払いであることを知っています。
- 解雇レビューは HR とマネージャーとの会話の代替ではありません。全員が忘れたものを拾うチェックリストです。
- 賃金・労働時間 Q&A はルールを引用しますが、際どい判断は人間レビュー用にフラグします。分類判断には結果が伴います。
