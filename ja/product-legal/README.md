# Product Counsel プラグイン

プロダクト法務ワークフロー: ローンチレビュー、マーケティング主張レビュー、機能リスク評価、および高速な「これは問題ですか?」トリアージ。あなたの実際のローンチレビュー履歴から学習したリスクキャリブレーションを中心に構築されています — 一般論ではなく、*あなたの* 会社で何がブロックされるか、です。

**すべての出力は弁護士レビューを前提とする下書きです — 引用付き、フラグ付き、ゲート付き — 法的結論ではありません。** プラグインは作業を行います: 文書を読み、プレイブックを適用し、課題を発見し、メモを下書きします。弁護士がレビューし、検証し、決定します。引用はソース別にタグ付けされるため、どれがリサーチツール由来でどれが要確認かが分かります。秘匿特権マーカーは保守的に適用され、誤って放棄されないようになっています。結果を伴うアクション — 提出、送信、実行 — は、明示的な確認の背後でゲートされます。

## 対象読者

| 役割 | 主なワークフロー |
|---|---|
| **プロダクト法務担当者** | ローンチレビュー、機能リスク評価、キャリブレーション維持 |
| **プロダクトマネージャー** | 「これは問題ですか?」のセルフサーブトリアージ |
| **マーケティング** | 出荷前の主張レビュー |
| **GC / 法務リーダーシップ** | エスカレートされた項目の機能リスク評価 |

## 初回実行: コールドスタート・インタビュー

ローンチトラッカー(Jira/Linear)に接続し、過去のローンチレビュー 10 件を読み、実際にブロックしたものと通したものを学習します。他のすべてのスキルが参照するリスクキャリブレーション表を構築します。

設定は `~/.claude/plugins/config/claude-for-legal-ja/product-legal-ja/CLAUDE.md` に保存され、プラグイン更新後も保持されます。

```
/product-legal-ja:cold-start-interview
```

## コマンド

| コマンド | 機能 |
|---|---|
| `/product-legal-ja:cold-start-interview` | コールドスタート・インタビュー |
| `/product-legal-ja:launch-review [PRD またはチケット]` | あなたのフレームワークに対するフルローンチレビュー |
| `/product-legal-ja:marketing-claims-review [コピー]` | マーケティング主張レビュー |
| `/product-legal-ja:is-this-a-problem [質問]` | 「これは問題ですか?」への高速回答 |
| `/product-legal-ja:matter-workspace` | 案件ワークスペースの管理(マルチクライアントの私的実務のみ) — 新規・一覧・切替・終了・解除 |

## スキル

| スキル | 目的 |
|---|---|
| **cold-start-interview** | インタビュー+過去ローンチレビューから `~/.claude/plugins/config/claude-for-legal-ja/product-legal-ja/CLAUDE.md` を書き出す |
| **launch-review** | あなたの会社にキャリブレーションされた、カテゴリ別レビュー |
| **marketing-claims-review** | 主張分類: 誇張表現/事実主張/比較主張/含意主張/絶対主張 |
| **feature-risk-assessment** | ローンチレビューでは不十分な場合の単一論点の深掘り |
| **is-this-a-problem** | 即座のトリアージで Slack の質問に対応 |
| **matter-workspace** | マルチクライアント実務向けに案件ワークスペースを作成・一覧・切替・終了。各クライアント/案件を分離し、コンテキストが漏れないようにする |

## インタラクティブコマンド vs. スケジュール実行エージェント

上記コマンドは起動した時に実行されます — 案件作業中向け。下記のエージェントはスケジュールで実行されます — 見ていない間に動くもの向け:

| エージェント | 監視対象 | デフォルト頻度 |
|---|---|---|
| **launch-watcher** | ローンチトラッカー(Jira/Linear)から法務レビューを要する可能性が高い近日中のローンチを監視。キャリブレーション表に従い、今後 30 日以内のローンチ日を持つチケットをフィルタ | 日次 |

## 連携(Integrations)

**まずリサーチツールを接続してください — 引用ガードレールはそれに依存します。** ない場合、すべての引用は `[verify]` タグが付き、各成果物の上の reviewer note にソースが検証されていないことが記録されます。スキルはどちらの場合でも動作しますが、リサーチツール(CourtListener)があれば検証作業があなたから離れます。

`.mcp.json` で構成されたコネクターが同梱されています:

- **Slack** — メッセージ検索、チャンネル読み取り、議論の発見(汎用バケット)
- **Google Drive** — ドキュメントの検索・読み取り・取得(汎用バケット)
- **Linear** — 課題追跡とプロジェクト管理
- **Atlassian** — Jira 課題および Confluence ページ
- **Asana** — タスクおよびプロジェクトの追跡

トラッカー接続時: コールドスタートはローンチ履歴を取得し、launch-review はチケットコンテキストを取得し、launch-watcher エージェントはカレンダーを監視します。

## クイックスタート

```
/product-legal-ja:cold-start-interview
```

その後:

```
/product-legal-ja:is-this-a-problem "Can we A/B test the pricing page?"
```

→ あなたのリスク表にキャリブレーションされた即時回答。

```
/product-legal-ja:launch-review PROJ-1234
```

→ カテゴリ別のフルレビュー、アクション項目付き。

## 学習の仕組み

`~/.claude/plugins/config/claude-for-legal-ja/product-legal-ja/CLAUDE.md` のプラクティスプロファイルは静的ではありません — プラグインを使うほど改善されます。スキルは、出力がチューニングすべきデフォルトを使った場合に教えてくれます。セットアップを再実行する、ファイルを直接編集する、またはスキルに新しいポジションを記録するよう指示できます。

## 注意事項

- キャリブレーション表が中核です。これが間違っていれば、すべてのレビューが間違います。リスクスタンスが変わったら再セットアップしてください(新しい規制当局、新しい同意判決、新しい GC)。
- `is-this-a-problem` は PM がセルフサーブで使うように設計されています。高速に回答し、必要に応じて本格的なレビューにルーティングします。
- 機能リスク評価はローンチの 10%、深掘りが必要なものに使用します。ほとんどは不要です — 文書化のための文書化はしないでください。

## 前提条件

一部の機能は外部連携(文書管理、ローンチトラッカー、eDiscovery、案件管理、規制フィード)を参照します。これらは同梱されていません — 環境にこれらのいずれかの MCP サーバーがあれば、関連する機能はそれを使用します。ない場合、プラグインはファイルアップロードと手動ワークフローにフォールバックします。`/product-legal-ja:cold-start-interview --check-integrations` を実行して、環境で何が利用可能か確認できます。

## 設定

設定は `~/.claude/plugins/config/claude-for-legal-ja/product-legal-ja/CLAUDE.md` に保存され、プラグイン更新後も保持されます — セットアップは一度だけ実行します。
