# handoffs/ — 学期末の案件引継ぎメモ

学期ごとのフォルダに、アクティブな案件ごとの引継ぎメモを 1 件ずつ保存。学期末に `/legal-clinic-ja:semester-handoff` が作成します。次学期のオンボーディング `/ramp` 実行時に、新たな担当案件について引き継ぐ学生が読みます。

## レイアウト

```
handoffs/
├── _README.md                             # このファイル
└── [YYYY-semester]/                       # 例: 2026-spring、2026-fall
    ├── _summary.md                        # 案件横断のロールアップ: 何が引き継がれ、誰から誰へ
    ├── [case-id].md                       # アクティブな案件 1 件につき 1 ファイル
    └── ...
```

## スラグ/フォルダの命名規則

学期フォルダ: `[year]-[spring|summer|fall]`。例:
- `2026-spring`
- `2026-summer`
- `2026-fall`

案件メモ: `deadlines.yaml` やインテイク記録の case_id を使用。案件単位の他ファイルと整合させます。

## 引継ぎメモに含める内容

- 案件サマリー(事実、プラクティスエリア、現在の状況)
- 引退する学生の氏名 + クライアントとの関係構築状況(該当時)
- 未処理の期限(`deadlines.yaml` から)
- オープンな論点/未決定事項
- コミュニケーション履歴(`client-comms/[case-id]/log.md` から)
- これまでに作成/提出した文書(案件ファイルへのポインター)
- 引き継ぐ学生が最初に知るべき/行うべきこと
- 教授からのフラグ(該当時)

## ワークフロー

1. `/legal-clinic-ja:semester-handoff` を学期末の 1 ~ 2 週間前に教授(または自分の案件について引退する学生自身)が実行する。
2. 案件ごとのメモと、サマリーを出力する。
3. 次のコホート(学年集団)は新学期開始時に `/legal-clinic-ja:ramp` を実行し、`/ramp` が新規の各学生に割り当てられた案件について引継ぎメモを浮上させる。

## 保存

引継ぎメモはディスクに残します。過去の引継ぎ記録は、クリニック自身の案件遷移記録として、また学期をまたいで案件がどう発展したかを学生が振り返るために有用です。
