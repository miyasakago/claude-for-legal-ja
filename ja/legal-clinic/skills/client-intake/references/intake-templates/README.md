# プラクティスエリア別インテイクテンプレート

コールドスタート時に教授のインテイクフォームから作成されます。提供されない場合、`/client-intake` は `client-intake/SKILL.md` の Step 2 に記載されたデフォルトの質問セットを使用します。

クリニックが扱う各プラクティスエリアごとに 1 ファイル:

- `immigration.md` — 在留資格、入国、過去の申請、出身国情勢、家族、犯罪歴、タイムライン
- `housing.md` — 住居種別、何が起きたか、賃貸契約/支払い、居住適合性、タイムライン
- `family.md` — 関係、子ども、安全性、既存命令、タイムライン
- `consumer.md` — 債務種別、連絡してきた相手、書類、提訴されたか、タイムライン

各テンプレートには、質問内容、質問順序、慎重な扱いに関する注記(例: 在留資格関連の文脈で犯罪歴を尋ねる際は理由を説明する)を含めます。
